# AGENTS.md

## Repository overview
This repository contains the Grid-Weather-Reporter Electron app, which reports simplified weather conditions from grid coordinates or city/state input.

## Working rules
- Stay within scope and avoid unrelated cleanup.
- Prefer small, targeted edits.
- Validate changes with the smallest relevant command.
- Keep GitHub sync actions safe and explicit.

## GitHub sync guidance
- Check repository status before making changes.
- Review branch and remote differences before fetching, merging, rebasing, or pushing.
- Never overwrite user work without consent.
- Use clear commit messages and prefer branch-based review flows.
- If asked to sync with GitHub, communicate the exact repo state before the push.
